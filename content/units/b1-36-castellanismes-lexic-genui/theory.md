## Els sufixos *-ada* i *-esa*

De molts verbs fem un nom femení amb el sufix *-ada*: diu l'acció o, amb un estri, el contingut.

> Cada tarda fan una **trucada** de mitja hora.

| Verb o nom | Nom en *-ada* |
|---|---|
| trucar | **trucada** |
| abraçar | **abraçada** |
| arribar | **arribada** |
| mirar | **mirada** |
| passejar | **passejada** |
| cullera | **cullerada** (el contingut) |

Dels adjectius fem noms de qualitat amb *-esa*, sempre amb *ss*:

| Adjectiu | Nom en *-esa* |
|---|---|
| bell | **bellesa** |
| ric | **riquesa** |
| pobre | **pobresa** |
| trist | **tristesa** |
| vell | **vellesa** |

> **Compte!** «Belleza», «riqueza» o «tristeza», amb *z*, són castellans → **bellesa**, **riquesa**, **tristesa**.

<!-- point: derivacio-cio-ment -->
## Els sufixos *-ció* i *-ment*

Molts verbs fan un nom d'acció amb *-ció* (femení) o amb *-ment* (masculí). No hi ha cap regla per saber quin toca: cal memoritzar cada parell.

> Dilluns farem la **presentació** del nou pòdcast.

| Verb | Nom | Gènere |
|---|---|---|
| presentar | **presentació** | femení |
| organitzar | **organització** | femení |
| publicar | **publicació** | femení |
| traduir | **traducció** | femení |
| emetre | **emissió** | femení |
| néixer | **naixement** | masculí |
| conèixer | **coneixement** | masculí |
| moure | **moviment** | masculí |
| llançar | **llançament** | masculí |

- L'article t'ajuda a comprovar el gènere: **la** presentació, **el** naixement.
- Davant de vocal, *la* s'apostrofa: **l'**organització, **l'**emissió.

> **Compte!** De *presentar*, el nom és **presentació**, no ~~presentament~~; de *conèixer*, **coneixement**, no ~~coneixeció~~.

<!-- point: derivacio-isme-ista -->
## Els sufixos *-isme* i *-ista*

El sufix *-isme* fa noms masculins d'activitat, actitud o moviment. El sufix *-ista* fa el nom de la persona, que serveix per a homes i dones.

> En Jordi es dedica al **periodisme**: és **periodista**.

| Activitat o moviment en *-isme* | Persona en *-ista* |
|---|---|
| **periodisme** | **periodista** |
| **turisme** | **turista** |
| **optimisme** | **optimista** |
| **feminisme** | **feminista** |
| **ecologisme** | **ecologista** |

- Algunes persones en *-ista* no tenen parella en *-isme*: **dentista**, **taxista**.

> **Compte!** La persona és *periodista* tant si és home com dona: ~~periodistessa~~ no existeix → **la periodista**. I no confonguis l'actitud amb la persona: ~~és un gran optimisme~~ → **és un gran optimista**.

## Compte amb el castellà: barbarismes de cada dia

A la conversa, els barbarismes més freqüents són paraules senceres del castellà. La taula en recull els més habituals amb la forma genuïna.

| Barbarisme | Forma genuïna |
|---|---|
| «bueno» | **bé** (per començar) / **bo** (l'adjectiu) |
| «vale» | **d'acord** |
| «pues» | **doncs** |
| «entonces» | **llavors** / **aleshores** |
| «apretar» el botó | **prémer** el botó |
| «vaso» | **got** |
| «empezar» | **començar** |
| «ordenador» | **ordinador** |

- *Bo* és l'adjectiu (*és molt bo*; davant d'un nom masculí, *bon*: *un bon llibre*); *bé*, l'adverbi (*parla bé*; *bé, comencem*).
- Per a una cosa sense trellat, el mot genuí és **ximpleria** (de *ximple*).

> **Compte!** ~~Bueno, pues entonces apretes el botó~~ → **Bé, doncs llavors prems el botó**. Quatre barbarismes en una sola frase!

<!-- point: expressions -->
## Expressions de cada dia

- **fer el préssec**: fer el ridícul. *En directe em vaig posar nerviós i vaig fer el préssec.*
- **fer-se un fart de**: atipar-se d'una cosa (és pronominal). *Ens vam fer un fart de riure.*
- **deixar-ho córrer**: abandonar una cosa. *Deixa-ho córrer: això no val la pena.*
- **anar de bòlit** (repàs): tenir molta feina i poc temps. *Aquesta setmana vaig de bòlit.*
