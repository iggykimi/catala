## El passat perifràstic

Per parlar d'un passat acabat, fem servir *anar* + infinitiu.

> Ahir **vaig anar** a Girona en tren.

| | anar | visitar |
|---|---|---|
| jo | **vaig anar** | **vaig visitar** |
| tu | **vas anar** | **vas visitar** |
| ell, ella, vostè | **va anar** | **va visitar** |
| nosaltres | **vam anar** | **vam visitar** |
| vosaltres | **vau anar** | **vau visitar** |
| ells, elles, vostès | **van anar** | **van visitar** |

- L'auxiliar canvia amb la persona. L'infinitiu no canvia mai.
- Va amb marcadors de passat acabat: **ahir**, **dissabte passat**, **la setmana passada**, **l'any passat**.
- En negatiu: no **vaig anar**, no **vam sortir**.
- També són correctes *vàrem* i *vàreu* (*vàrem anar*). Aquí practiquem *vam* i *vau*.

> **Compte!** ~~Ahir vaig a anar~~ → Ahir **vaig anar**. Sense *a*: és passat.

<!-- point: perfet -->
## El perfet

Per parlar d'un passat recent, fem servir *haver* + participi.

> Avui **he anat** a Girona en tren.

| | |
|---|---|
| jo | **he** dinat |
| tu | **has** dinat |
| ell, ella, vostè | **ha** dinat |
| nosaltres | **hem** dinat |
| vosaltres | **heu** dinat |
| ells, elles, vostès | **han** dinat |

| infinitiu | participi |
|---|---|
| parlar | parl**at** |
| perdre | perd**ut** |
| dormir | dorm**it** |

- El participi regular: *-ar* → **-at** (*he parlat*); *-re* → **-ut** (*he perdut*); *-ir* → **-it** (*he dormit*).
- Va amb marcadors que toquen el present: **avui**, **aquest matí**, **aquesta setmana**, **aquest mes**, **aquest any**, **enguany**.
- En negatiu: no **he dinat**, no **hem sortit**.

> **Compte!** ~~Avui vaig dinar~~ → Avui **he dinat**. Amb *avui* fem servir el perfet.

<!-- point: participis-irregulars -->
## Participis irregulars

Alguns verbs molt usats tenen un participi que cal saber de memòria.

> He **fet** la maleta i he **dit** adéu a tothom.

| infinitiu | participi |
|---|---|
| fer | **fet** |
| dir | **dit** |
| veure | **vist** |
| ser, estar | **estat** |
| tenir | **tingut** |
| poder | **pogut** |
| voler | **volgut** |
| saber | **sabut** |
| venir | **vingut** |

- *Ser* i *estar* fan el mateix participi: **estat**.
- Després de *he, has, ha…* sempre va el participi, mai l'infinitiu.
- Hi ha més participis irregulars (*escrit*, *obert*), però aquí no els practiquem.

> **Compte!** ~~he tenit~~ → **he tingut**. ~~he saput~~ → **he sabut**.

<!-- point: compte-castella -->
## Compte amb el castellà: *vaig anar* i *vaig a anar*

S'assemblen molt, però una forma és passat i l'altra és futur.

> Ahir **vaig visitar** Girona. Demà **vaig a visitar** Tarragona.

- Sense *a*, és **passat**: Ahir **vaig sortir**.
- Amb *a*, és **futur**: Demà **vaig a sortir**. És *anar a* + infinitiu.
- *Vaig anar* i *vaig a anar* no són el mateix: el futur porta *a*.
- Mira el marcador: *ahir* → passat; *demà* → futur.

> **Compte!** ~~Ahir vaig a sortir~~ → Ahir **vaig sortir**. ~~Demà vaig sortir~~ → Demà **vaig a sortir**.

<!-- point: expressions -->
## Expressions de viatge

- **perdre el tren**: no arribar a temps per pujar al tren. *Vam sortir tard i vam perdre el tren.* També: perdre una bona oportunitat.
- **fer un tomb**: passejar una estona, sense pressa. *Diumenge fem un tomb pel barri.*
- **anar d'excursió**: fer una sortida a la muntanya o al camp. *Diumenge anem d'excursió a Montserrat.*
