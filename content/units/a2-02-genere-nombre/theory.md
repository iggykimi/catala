## El femení de noms i adjectius

Per fer el femení, normalment afegim *-a* al masculí.

> En Pau és **alt** i la Laia és **alta**.

| masculí | femení |
|---|---|
| alt | **alta** |
| treballador | **treballadora** |
| cambrer | **cambrera** |
| company | **companya** |
| simpàtic | **simpàtica** |
| amic | **amiga** |
| germà | **germana** |
| cosí | **cosina** |
| veí | **veïna** |

- L'accent final desapareix: **germà → germana**, **cosí → cosina**.
- *Veí* fa **veïna**, amb dièresi.
- *Amic* canvia la *c* per *g*: **amiga**.
- Hi ha femenins irregulars (per exemple, amb *-essa*). Aquí no els practiquem.

> **Compte!** ~~La meva germà~~ → **La meva germana**.

<!-- point: plural -->
## El plural: *-s*, *-es* i *-os*

El plural dels masculins afegeix *-s*. El dels femenins acaba en *-es*.

> Els **nens** i les **nenes** juguen al parc.

| singular | plural |
|---|---|
| nen | **nens** |
| germà | **germans** |
| veí | **veïns** |
| casa | **cases** |
| peix | **peixos** |
| pastís | **pastissos** |
| feliç | **feliços** |
| cançó | **cançons** |
| amiga | **amigues** |
| boca | **boques** |
| platja | **platges** |
| llengua | **llengües** |

- Molts masculins acabats en *-x*, *-ç* o *-s* fan **-os**: **peixos**, **feliços**, **pastissos**.
- Els noms acabats en *-ó* fan **-ons**, sense accent: **cançons**.
- En el femení, la grafia canvia per mantenir el so: *-ca → -ques*, *-ga → -gues*, *-ja → -ges*, *-gua → -gües*.
- Hi ha més plurals irregulars. Aquí no els practiquem.

> **Compte!** ~~platjes~~ → **platges**. ~~peixs~~ → **peixos**.

<!-- point: concordanca -->
## Concordança i adjectius invariables

L'adjectiu va amb el mateix gènere i nombre que el nom.

> Les meves veïnes són **altes** i **simpàtiques**.

Alguns adjectius són iguals en masculí i en femení, i només fan el plural:

| singular | plural |
|---|---|
| alegre | **alegres** |
| amable | **amables** |
| jove | **joves** |
| gran | **grans** |
| difícil | **difícils** |
| puntual | **puntuals** |

- *Feliç* és igual al singular, però el plural té dues formes: **feliços** (masculí) i **felices** (femení).
- Alguns noms de persona també són iguals: **el dentista**, **la dentista**.

> **Compte!** ~~Una noia jova~~ → **Una noia jove**.

<!-- point: compte-castella -->
## Compte amb el castellà: noms de gènere diferent

Alguns noms tenen un gènere en català i un altre en castellà.

> **La calor** d'agost no em deixa dormir.

| femení en català | masculí en castellà |
|---|---|
| la dent | «el diente» |
| la calor | «el calor» |
| l'olor | «el olor» |
| la suor | «el sudor» |
| la resta | «el resto» |
| l'anàlisi | «el análisis» |

| masculí en català | femení en castellà |
|---|---|
| el senyal | «la señal» |
| el dubte | «la duda» |
| el costum | «la costumbre» |
| l'avantatge | «la ventaja» |

- Amb *l'* no es veu el gènere. Fixa't en altres paraules: **una olor**, **un avantatge**, **aquesta anàlisi**.
- Al plural, *anàlisi* no canvia: **les anàlisis**.

> **Compte!** ~~Una dubte~~ → **un dubte**. ~~Aquest calor~~ → **aquesta calor**.

<!-- point: expressions -->
## Expressions: caràcter i descripció

- **ser un tros de pa**: ser molt bona persona. *El meu cap és un tros de pa.*
- **tenir mala llet**: tenir mal caràcter o mala intenció. *La veïna del tercer té molta mala llet.*
- **ser més llarg que un dia sense pa**: ser molt llarg, no acabar mai. *La reunió va ser més llarga que un dia sense pa.*

L'adjectiu *llarg* concorda amb el nom: **una reunió més llarga**.
