<!-- point: be-i-v -->
## La *b* i la *v*

La *b* i la *v* sonen igual, però s'escriuen diferent. Algunes regles ajuden; la resta es memoritza.

> **Rebre** porta *b*; **haver** i **provar** porten *v*.

| Regla | Exemples |
|---|---|
| *b* darrere de *m* | ombra, embaràs, també |
| *b* en *bl-* i *br-* | blanc, braç, obrir |
| *b* en els verbs en *-rebre* | rebre, concebre |
| *v* darrere de *n* | enviar, invàlid, convalescència |
| *v* inicial en *va-*, *ve-*, *vi-* | vacuna, venir, verd |

- Amb *b*: **rebre**, **trobar**, **beure**, **treballar**, **escombrar**, **berruga**, **calb**, **mòbil**.
- Amb *v*: **haver**, **provar**, **govern**, **advocat**, **veure**, **ventre**, **llavi**, **cervell**.

> **Compte!** *Trobar* porta *b*, però *provar* porta *v*: ~~probar~~ → **provar**. I *haver* sempre amb *v*: ~~haber~~ → **haver**.

<!-- point: consonants-finals -->
## Les consonants finals

A final de mot, algunes consonants sonen igual. Per saber quina lletra toca, busquem un mot de la família on la consonant soni: el femení, el plural o el verb.

> **verd** → **verda** (la *d* sona) → **verds**.

| Masculí | Femení | Plural | Família |
|---|---|---|---|
| verd | verda | verds | verdor |
| groc | groga | grocs | grogor |
| blanc | blanca | blancs | blanquejar |
| fred | freda | freds | fredor |
| curt | curta | curts | escurçar |
| llarg | llarga | llargs | allargar |
| calb | calba | calbs | calvície |
| net | neta | nets | netejar |
| sec | seca | secs | assecar |

- *Sap* i *saben* són del verb *saber*: la *b* sona entre vocals (*saben*), però a final de mot s'escriu *p*: *sap*.
- Davant de *e* i *i*, el so de *c* s'escriu *qu*: *blanques*, *seques*.

> **Compte!** ~~verts~~ → **verds**, ~~grogs~~ → **grocs**, ~~sab~~ → **sap**. Busca sempre el femení o el verb.

<!-- point: ix-x-tx-ig -->
## *ix*, *x*, *tx* i *ig*

El so palatal (el de *caixa*) s'escriu de quatre maneres. La posició dins el mot decideix.

> **xarop**, **cuixa**, **dutxa**, **faig**: el mateix so, quatre lletres.

| On | S'escriu | Exemples |
|---|---|---|
| a principi de mot | *x* | xarop, xeringa |
| darrere d'un diftong (*ai*, *ei*, *oi*, *ui*) | *ix* | aixella, cuixa, queixal, coixí, maduixa |
| entre vocals sense diftong | *x* | examen, pròxim, exacte |
| en *dutxa*, *cotxe*, *despatx* i família | *tx* | dutxa, dutxar-se, cotxe, despatx |
| a final de mot | *ig* | mig, desig, bateig, passeig, fuig |
| formes verbals | *ig* i *-eix-* | vaig, faig, veig; pateix, serveix |

- Els verbs incoatius (*patir*, *servir*) afegeixen *-eix-*: *pateix*, *serveix*.
- Hi ha excepcions, però aquí no les practiquem.

> **Compte!** ~~cuxa~~ → **cuixa**, ~~ixarop~~ → **xarop**, ~~faix~~ → **faig**.

<!-- point: compte-castella -->
## Compte amb el castellà: la *b/v* contrària

En aquests mots, el català i el castellà no fan servir les mateixes lletres. Són els errors més freqüents i cal memoritzar-los.

| Català | Castellà |
|---|---|
| haver | «haber» |
| provar | «probar» |
| govern | «gobierno» |
| advocat | «abogado» |
| cervell | «cerebro» |
| ventre | «vientre» |
| treballar | «trabajar» |
| escombrar | «barrer» |
| berruga | «verruga» |
| mòbil | «móvil» |
| calb | «calvo» |
| llavi | «labio» |

- Amb *v* en català i *b* en castellà: **haver**, **provar**, **govern**, **advocat**, **cervell**.
- Amb *b* en català i *v* en castellà: **berruga**, **mòbil**, **calb**.
- *Treballar* i *escombrar* canvien tota la paraula, no només la lletra.

> **Compte!** ~~abogado~~ → **advocat**, ~~verruga~~ → **berruga**, ~~traballa~~ → **treballa**.

<!-- point: expressions -->
## Expressions del cos

- **fer-se mala sang**: amoïnar-se, patir per alguna cosa. *No et facis mala sang per l'operació.*
- **tenir bona mà**: tenir traça o habilitat. *La Núria té bona mà amb els nens.*
- **no tenir cap ni peus**: no tenir sentit ni lògica. *Aquest diagnòstic no té cap ni peus.*
- **tenir sang freda**: mantenir la calma en una situació difícil. *El cirurgià té sang freda.*

<!-- point: comprensio -->
## Llegir i entendre

Llegeix el text sencer abans de mirar les preguntes. Subratlla les paraules del cos que coneguis: t'ajudaran a situar cada resposta. Després busca la frase exacta que respon cada pregunta i comprova que les altres opcions diuen una altra cosa.
