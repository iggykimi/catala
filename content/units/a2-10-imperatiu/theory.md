<!-- point: imperatiu-afirmatiu -->
## L'imperatiu afirmatiu

L'imperatiu serveix per donar ordres i instruccions de cuina.

> **Talla** el pa. **Remeneu** la sopa.

| | tu | vosaltres |
|---|---|---|
| -ar | **talla** | **talleu** |
| -re, -er | **beu**, **encén** | **beveu**, **enceneu** |
| -ir | **obre** | **obriu** |
| -eix- | **afegeix** | **afegiu** |

- A una persona: *talla*, *obre*, *afegeix*. A més d'una: *talleu*, *obriu*, *afegiu*.
- Els verbs en *-eix-* mantenen *-eix-* amb *tu*: **serveix**, **fregeix**.
- Aquí practiquem les formes de *tu* i *vosaltres*.

> **Compte!** ~~Obris la finestra~~ → **Obre la finestra**. *Obris* només va amb *no*.

<!-- point: imperatiu-negatiu -->
## L'imperatiu negatiu

En negatiu, l'imperatiu canvia: la forma de *tu* porta una *-s*.

> **Posa** sal. → No **posis** sal.

| | tu | vosaltres |
|---|---|---|
| -ar | no **parlis** | no **parleu** |
| -ir | no **obris** | no **obriu** |
| -eix- | no **serveixis** | no **serviu** |

- Amb *vosaltres*, sovint no canvia res: *parleu* / no *parleu*; *obriu* / no *obriu*.
- I *beure*: *beu* → no *beguis*.
- Alguns verbs canvien l'ortografia: *tocar* → no **toquis**; *trencar* → no **trenquis**.

> **Compte!** ~~No parla~~ → **No parlis**. El negatiu no és l'afirmatiu amb *no*.

<!-- point: imperatius-irregulars -->
## Els imperatius irregulars

Set verbs tenen formes pròpies. Les has d'aprendre de memòria.

> **Ves** al mercat. No **vagis** amb el cotxe.

| | tu | vosaltres | no + tu | no + vosaltres |
|---|---|---|---|---|
| anar | **ves** | **aneu** | no **vagis** | no **aneu** |
| venir | **vine** | **veniu** | no **vinguis** | no **vingueu** |
| fer | **fes** | **feu** | no **facis** | no **feu** |
| dir | **digues** | **digueu** | no **diguis** | no **digueu** |
| ser | **sigues** | **sigueu** | no **siguis** | no **sigueu** |
| tenir | **tingues** | **tingueu** | no **tinguis** | no **tingueu** |
| veure | **veges** | **vegeu** | no **vegis** | no **vegeu** |

- Amb *tu*, la forma sempre canvia: *fes* → no *facis*; *digues* → no *diguis*.
- Amb *vosaltres*, gairebé sempre és igual: *feu* / no *feu*. Excepció: *veniu* / no *vingueu*.

> **Compte!** ~~No fes tard~~ → **No facis tard**. ~~No veniu ara~~ → **No vingueu ara**.

<!-- point: imperatiu-amb-pronom -->
## L'imperatiu amb un pronom

En afirmatiu, el pronom va darrere del verb, unit amb guionet o apòstrof.

> **Obre-la**. **Digues-me** la recepta.

| el pronom | exemple |
|---|---|
| *la* | **obre-la**, **tanca-la** |
| *el* | **obre'l**, **prova'l** |
| *les* | **obre-les**, **tasta-les** |
| *ho* | **fes-ho**, **fregeix-ho** |
| *me* | **digues-me**, **ajuda'm** |
| *li* | **porta-li**, **digues-li** |
| *ne* | **menja'n**, **agafa'n** |
| *hi* | **posa-hi**, **afegeix-hi** |
| *te* | **asseu-te** |

- Darrere de vocal, el pronom curt s'apostrofa: *prova'l*, *ajuda'm*. Darrere de consonant, sencer: *digues-me*.
- En negatiu, el pronom va davant: no **l'obris**, no **em diguis**, no **t'asseguis**.
- *Seure* no porta pronom: **seu aquí**. *Asseure's*, sí: **asseu-te aquí**. Amb *vosaltres*: **seieu**, **asseieu-vos**.

> **Compte!** ~~La obre~~ → **Obre-la**. ~~Asseu aquí~~ → **Asseu-te aquí**.

<!-- point: compte-castella -->
## Compte amb el castellà: el negatiu i les ordres

Les ordres no són iguals en castellà i en català. En negatiu, no facis servir l'afirmatiu amb *no*.

> ~~No parla~~ → **No parlis**. ~~Abre~~ → **Obre**.

- En negatiu, la forma canvia: *posa* → no *posis*; *fes* → no *facis*.
- Algunes ordres són molt diferents: **obre** (no ~~abre~~), **posa** (no ~~pon~~), **surt** (no ~~sal~~), **menja** (no ~~come~~), **fes** (no ~~haz~~).

> **Compte!** ~~No tingues pressa~~ → **No tinguis pressa**. El negatiu no és l'afirmatiu amb *no*.

<!-- point: expressions -->
## Expressions per animar i avisar

- **au, va!**: per animar algú a fer una cosa. *Au, va, tasta el brou!*
- **vinga!**: per fer córrer algú o per animar. *Vinga, que arribem tard!*
- **tranquil!**: per calmar algú que pateix. *Tranquil, que t'ajudo jo!*
- **ves amb compte!**: per avisar d'un perill. *Ves amb compte, que crema!*
