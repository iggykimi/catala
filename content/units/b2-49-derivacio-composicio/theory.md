## Els prefixos: des-, in-, re-, sots-, ex- i vice-

Els prefixos van sempre units al mot, sense guionet ni espai. Canvien el sentit del mot base: el neguen (*in-*), el desfan (*des-*), el repeteixen (*re-*) o marquen un càrrec (*sots-*, *ex-*, *vice-*).

> congelar → **descongelar**; estable → **inestable**; escalfar → **reescalfar**; director → **sotsdirector**.

| Prefix | Valor | Exemples |
|---|---|---|
| des- | desfà o inverteix | **descongelar**, **dessalar** (treure la sal), **descafeïnat** |
| in- | nega | **insípid** (sense gust), **incomestible**, **inestable** |
| re- | repeteix | **reescalfar**, **reobrir**, **reaprofitar** |
| sots- | segon en el càrrec | **sotscap**, **sotsdirector** |
| ex- | que ja no és | **exministre**, **exalcalde**, **excompany** |
| vice- | substitut | **vicepresident**, **vicerector** |

El prefix *in-* canvia de forma segons la lletra següent: **im-** davant de *b*, *p* i *m* (**impossible**, **impacient**); **il·l-** davant de *l* (**il·legal**); **irr-** davant de *r* (**irregular**, **irresponsable**).

Alguns verbs porten prefix i sufix alhora: calent → **escalfar**; sal → **dessalar**; greix → **desgreixar**.

> **Compte!** El prefix no porta mai guionet: ~~ex-ministre~~, ~~vice-president~~, ~~re-escalfar~~ → **exministre**, **vicepresident**, **reescalfar**.

## Els sufixos: noms, adjectius i diminutius

Els sufixos formen mots nous i en marquen la categoria: *preparació* (nom), *saborós* (adjectiu), *trosset* (diminutiu).

> cuina → **cuiner**; sabor → **saborós**; tros → **trosset**.

| Sufix | Valor | Exemples |
|---|---|---|
| -ció, -sió | acció o resultat | **preparació**, **cocció**, **degustació**, **guarnició** |
| -ment | acció o resultat | **amaniment**, **farciment**, **assortiment** |
| -ada | contingut o porció | **cullerada**, **tallada**, **fornada**, **platada** |
| -dor, -dora | màquina | **batedora**, **espremedora**, **rentadora** |
| -er, -era | ofici o recipient | **forner**, **peixater**, **cuiner**, **fruitera** |
| -eria | botiga | **pastisseria**, **carnisseria**, **peixateria** |
| -ós, -osa | abundància | **saborós**, **greixós**, **sucós**, **oliós** |
| -able, -ible | que es pot | **comestible**, **potable**, **menjable** |
| -et, -eta | petit | **trosset**, **platet**, **cullereta**, **panet** |

- **El fruiter** és l'arbre o el venedor; **la fruitera** és el recipient per a la fruita.
- Compte amb els canvis ortogràfics: tros → **trosset**, amb doble essa.

> **Compte!** ~~troset~~ → **trosset**; ~~pescaderia~~ (castellà) → **peixateria**.

## Els mots compostos i el guionet

Els mots compostos s'escriuen en un sol mot o amb guionet, segons el cas. Els compostos de verb + nom en plural van junts, i també els de nom + adjectiu.

> obrir + llaunes → **obrellaunes**; all + oli → **allioli**; boca + moll → **bocamoll**.

- Sense guionet, en un sol mot: **escuradents**, **obrellaunes**, **rentaplats**, **eixugamans**, **bocamoll**, **allioli**, **aiguardent**.
- Amb guionet: **penja-robes** (excepció tradicional), **gira-sol**, **nord-est**, **sud-oest** (punts cardinals) i **poti-poti** (repetició expressiva).
- El prefix **no-** porta sempre guionet: **no-violència**, **no-res**.
- El plural: **gira-sol** → **gira-sols**; **bocamoll** → **bocamolls**; els compostos acabats en *-s* són invariables: **els escuradents**, **els penja-robes**, **els rentaplats**.

> **Compte!** ~~escura-dents~~ → **escuradents**; ~~penjarobes~~ → **penja-robes**. Cada compost té la seva grafia: cal memoritzar-la.

<!-- point: compte-prefixos -->
## Compte amb el castellà: el prefix va unit al mot

En castellà, molta gent escriu aquests prefixos amb guionet o separats («ex-ministro», «vice-presidente»). En català, els prefixos van sempre units al mot base.

> ~~ex-ministre~~ → **exministre**; ~~ex-company~~ → **excompany**; ~~vice-president~~ → **vicepresident**.

- També: **exmarit**, **exalcalde**, **exjugador**, **exdirector**.
- El prefix hi va unit fins i tot davant de vocal: ~~ex-alcalde~~ → **exalcalde**; ~~re-obrir~~ → **reobrir**.
- L'únic que porta guionet és **no-**: **no-violència**.

> **Compte!** Si dubtes entre guionet, espai o res, tria res: ~~ex cuiner~~ → **excuiner**.

## Expressions de la cuina

- **fer-se la boca aigua**: venir saliva a la boca per les ganes de menjar. *Amb l'olor del rostit se'm fa la boca aigua.*
- **ser de bon menjar**: tenir bon apetit i gaudir del menjar. *El meu germà és de bon menjar: li agrada tot.*
- **tenir bon paladar**: saber apreciar els sabors i la qualitat del menjar. *La Carla té bon paladar per als olis.*
- **llepar-se'n els dits**: gaudir molt d'un menjar. *Amb aquests canelons te'n lleparàs els dits.*
- **menjar amb els ulls**: mirar el menjar amb moltes ganes abans de tastar-lo. *El pare ja menja amb els ulls.*

<!-- point: comprensio -->
## Llegir i entendre

Llegeix el text sencer abans de mirar les preguntes. Fixa't en els mots derivats i compostos: el prefix i el sufix t'ajuden a entendre el significat (*descongelar* = treure del congelador; *cullerada* = el contingut d'una cullera). Després busca al text la frase que respon cada pregunta.
