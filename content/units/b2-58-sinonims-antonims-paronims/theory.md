## Parònims propers

Els parònims són paraules que s'assemblen però signifiquen coses diferents. En aquesta unitat en practiquem quatre parells.

> Un antivirus **eficaç** detecta tots els virus. Un programa **eficient** gasta poca memòria.

| Parell | Significat | Exemple |
|---|---|---|
| **eficaç** | que aconsegueix l'efecte desitjat | un remei eficaç |
| **eficient** | que gasta pocs recursos | un motor eficient |
| **actitud** | manera de comportar-se | una actitud positiva |
| **aptitud** | capacitat per fer una cosa | aptitud per als idiomes |
| **infringir** | incomplir (una norma) | infringir les normes |
| **infligir** | causar (un càstig, un dolor) | infligir una multa |
| **prevenir** | impedir, prendre mesures contra una amenaça | prevenir els incendis |
| **preveure** | veure per endavant, anunciar el futur | preveure un augment |

- **Actitud** és com ets; **aptitud** és què saps fer.
- **Infringir** porta una norma darrere; **infligir** porta un càstig.
- **Prevenir** és actuar contra una amenaça; **preveure** és dir què passarà.

> **Compte!** ~~una mesura eficient que sempre funciona~~ → una mesura **eficaç**. ~~Té bona aptitud amb els clients~~ → bona **actitud**. ~~infligir les normes~~ → **infringir** les normes. ~~preveure els incendis netejant el bosc~~ → **prevenir** els incendis.

## Sinònims per variar el text

Els sinònims diuen gairebé el mateix amb una altra paraula. Serveixen per no repetir i per triar el to: neutre o formal.

> Vaig **fer** la reserva per internet. → Vaig **efectuar** la reserva per internet. (= més formal)

- **triar** = **escollir**; **començar** = **iniciar**; **acabar** = **concloure** (formal).
- **utilitzar** = **fer servir**; **enviar** = **trametre** (formal).
- **esborrar** = **eliminar** (un fitxer, una foto); **fer** = **efectuar** (una reserva, un pagament).
- **problema** = **inconvenient** (formal); **error** = **errada**.

Dos sinònims no sempre es poden intercanviar. A l'ordinador, l'expressió fixa és **iniciar la sessió**. I el gènere pot canviar: *un error* és masculí i *una errada* és femení, de manera que l'article també canvia.

> **Compte!** ~~He tret el model més barat~~ → He **triat** (o **escollit**) el model més barat. *Treure* és fer sortir una cosa d'un lloc; *trair* és enganyar la confiança d'algú.

<!-- point: antonims-prefixos -->
## Antònims amb prefixos

Molts antònims es formen amb els prefixos *in-* i *des-*. El prefix *in-* canvia segons la lletra següent.

> La contrasenya és **segura**. → La contrasenya és **insegura**.

| Prefix | Davant de | Exemple |
|---|---|---|
| **in-** | la majoria de lletres | segur → **insegur**, visible → **invisible** |
| **im-** | *b* i *p* | possible → **impossible**, pacient → **impacient** |
| **il-** | *l* | legal → **il·legal**, legible → **il·legible** |
| **ir-** | *r* | real → **irreal**, responsable → **irresponsable** |
| **des-** | l'acció contrària | connectar → **desconnectar**, fer → **desfer**, carregar → **descarregar** |

- Amb *des-*: **desconegut**, **desordre**, **desacord**, **desaparèixer**, **desinstal·lar**, **desbloquejar**.
- L'antònim d'*eficaç* és **ineficaç**; el d'*estable*, **inestable**.

> **Compte!** El prefix no sempre és *des-*: ~~despossible~~ → **impossible**, ~~deslegal~~ → **il·legal**, ~~inconnectar~~ → **desconnectar**.

<!-- point: compte-paronims -->
## Compte amb el castellà: parònims que no coincideixen

En castellà, aquests parells són paraules ben diferents; en català s'assemblen i es confonen. El castellà, aquí, no ajuda.

| En català | Significat | En castellà |
|---|---|---|
| **dada / data** | informació / dia del calendari | «dato» / «fecha» |
| **signar / assignar** | posar la signatura / donar una feina | «firmar» / «asignar» |
| **record / rècord** | memòria / marca esportiva | «recuerdo» / «récord» |
| **deute / deure** | diners que deus / obligació | «deuda» / «deber» |

- Les **dades** personals; la **data** de naixement.
- **Signar** un contracte; **assignar** una tasca a algú.
- Un **record** d'infantesa; el **rècord** del món.
- Pagar un **deute**; el **deure** de votar.

> **Compte!** ~~les dates personals~~ → les **dades** personals. ~~assignar el contracte~~ → **signar** el contracte. ~~un rècord d'infantesa~~ → un **record** d'infantesa.

<!-- point: expressions -->
## Expressions per parlar clar

- **dir les coses pel seu nom**: dir la veritat sense eufemismes. *Diguem les coses pel seu nom: això és un frau.*
- **no és el mateix**: dues coses semblants són diferents. *No és el mateix un virus que un error.*
- **dir-ho amb totes les lletres**: dir una cosa delicada obertament. *Li ho va dir amb totes les lletres.*
- **amb pèls i senyals**: amb tots els detalls. *M'ho va explicar amb pèls i senyals.*
- **posar blanc sobre negre**: escriure un acord perquè quedi clar. *Ho vam posar blanc sobre negre.*
- **explicar fil per randa**: explicar amb ordre, pas a pas. *Explica'm fil per randa què has fet.*

<!-- point: comprensio -->
## Llegir i entendre

Llegeix el text sencer abans de mirar les preguntes. Fixa't en les paraules de la unitat: els parònims (*dades/data*, *signar/assignar*), els sinònims i els antònims t'ajuden a entendre el sentit exacte de cada frase. Després busca al text la frase que respon cada pregunta.
